# Device testing

## Expo Go

Expo Go can be used for:

- Splash/Home/Radio visual validation
- navigation
- direct live-stream foreground playback
- play/pause
- MiniPlayer state

Expo Go must **not** be used to validate:

- Android foreground media playback service
- lock-screen controls
- sustained background playback

Those features depend on native configuration generated by the `expo-audio` config plugin.

## Android development build — local

After pulling native/config changes:

```bash
npm install
npx expo prebuild --clean
npx expo run:android --device
```

Then start Metro for the installed development build:

```bash
npx expo start --dev-client
```

Requirements:

- Android device connected by USB
- Developer options enabled
- USB debugging enabled
- Android SDK/adb available

## Android development build — EAS

One-time project/account setup:

```bash
npx eas-cli@latest login
npx eas-cli@latest init
```

Build:

```bash
npx eas-cli@latest build --platform android --profile development
```

The `development` profile generates an installable APK with the project's native `expo-audio` configuration.

## Background acceptance test

1. Start LAZ1310.
2. Open Radio.
3. Press Play.
4. Return to Home; MiniPlayer must remain synchronized.
5. Put the app in the background.
6. Lock the screen.
7. Audio must continue.
8. Android must show a media notification / lock-screen controls.
9. Pause from the system media control.
10. Reopen the app and confirm UI state.
11. Switch Wi-Fi → cellular data and observe reconnect behavior.
